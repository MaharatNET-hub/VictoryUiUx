# Victory B2B — نشر التطبيقين

مجلد جاهز للرفع على أي استضافة ملفات ثابتة (Static Hosting).

## المحتويات
```
index.html            صفحة اختيار التطبيق (نقطة البداية)
merchant.html         تطبيق التاجر
supplier.html         تطبيق المورد
support.js            محرّك التشغيل (مطلوب)
android-frame.jsx     إطار الجهاز (مطلوب)
image-slot.js         مكوّن مساعد
assets/               اللوغو وصور التصنيفات
```

## الرفع
ارفع محتويات هذا المجلد كما هي إلى جذر الموقع. نقطة البداية `index.html`.

يعمل مباشرة على: Netlify (اسحب المجلد)، Vercel، Cloudflare Pages، GitHub Pages، أو أي استضافة عادية عبر FTP.

## ملاحظات
- الملفات تُحمَّل بمسارات نسبية، فلا حاجة لأي إعداد إضافي.
- لا يعمل بفتح الملف من القرص مباشرة (file://) — لازم سيرفر. للتجربة محلياً:
  `python3 -m http.server 8080` ثم افتح `http://localhost:8080`
- الخطوط (Cairo / Montserrat) تُحمَّل من Google Fonts، فيلزم اتصال إنترنت.
