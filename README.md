# Victory — تطبيقات شبكة التوريد الذكية

ثلاثة تطبيقات (عربي / إنكليزي):

- `merchant.html` — تطبيق التاجر
- `supplier.html` — تطبيق المورد
- `collector.html` — تطبيق مندوب التحصيل
- `index.html` — صفحة اختيار التطبيق

## التشغيل
افتح `index.html` عبر أي سيرفر ثابت (GitHub Pages يعمل مباشرة).
لا تفتح الملفات بـ file:// لأن بعض المتصفحات تمنع تحميل السكربتات المحلية.

## GitHub Pages
Settings → Pages → Branch: main → / (root)

## الملفات
- `assets/` الصور والشعار
- `support.js` محرك العرض (مطلوب لكل التطبيقات)
