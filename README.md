# Victory — تطبيقا التاجر والمورد

## المحتوى
- `Victory Merchant App.dc.html` — تطبيق التاجر
- `Victory Supplier App.dc.html` — تطبيق المورد
- `support.js` — ملف التشغيل (مطلوب بجانب الملفين)
- `assets/` — كل الصور والشعارات
- `screens/` — لقطات الشاشات المرجعية
- `live/` — نسخة HTML مستقلة لكل تطبيق (ملف واحد بلا ملفات جانبية)

## التشغيل لايف
الطريقة الأسهل: ارفع محتوى `live/` على أي استضافة ثابتة (Netlify / Vercel / GitHub Pages).

أو ارفع المجلد كامل كما هو، بشرط بقاء `support.js` و `assets/` بجانب ملفي التطبيق.
